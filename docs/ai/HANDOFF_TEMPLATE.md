## Verification receipts

For every receipt include:

- Receipt ID and acceptance-item IDs supported.
- Action type: command, browser, manual inspection, or artifact.
- Exact action.
- Collaborator-reported status.
- Local status: `unverified`, `pass`, `fail`, or `not-applicable`.
- Exit code when applicable.
- Bounded evidence and completion time.

Do not convert collaborator prose into a local pass.

## Remaining risk

List unresolved acceptance IDs, failed/unrun receipts, reasoned waivers, stale-packet risk, and authority-gated work. If Shipped used an override, quote the reason and keep it visibly distinct from verification.

## Resume

First exact source symbol/file, smallest next test, and any authority gate.
