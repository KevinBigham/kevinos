# KevinOS change procedure

Use for any behavior or state edit. Read `AGENTS.md` and the relevant domain doc. Run `node tools/doctor.js` and the smallest baseline. Write a compact work packet. Keep `index.html` ES5 and single-file. Classify every state field, call `touch/save/bury` correctly, add a focused characterization, run it immediately, then run `sh test/run.sh`. Browser-check user-facing changes. Update `docs/CURRENT_STATE.md` with exact evidence and unresolved risk.
