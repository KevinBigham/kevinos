# KevinOS audit procedure

Read `AGENTS.md`, `docs/CURRENT_STATE.md`, and the relevant contract. Run the doctor and existing tests without editing. Inspect code and browser behavior. Report findings by severity with exact source symbol/evidence, user impact, smallest safe correction, and verification. Distinguish historical claims from current code. Never change, push, deploy, or mutate external state during an audit.
